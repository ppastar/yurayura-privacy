YuraYura 개인정보처리방침

시행일: 2026년 10월 20일 (프리셋 받기·구글 로그인 반영)

YuraYura(이하 "앱")는 휴대폰 배경화면에 캐릭터가 줄에 매달려 흔들리는 라이브 배경화면 앱입니다. 앱은 회원가입이 없습니다. 선택 기능인 '프리셋 받기'에서 구글 계정으로 로그인할 때만 아래 2번의 정보를 처리합니다.

1. 앱이 다루는 정보

  • 사진: 사용자가 직접 고른 사진(배경·캐릭터 이미지)은 휴대폰 안의 앱 저장공간에만 저장되며, 밖으로 보내지 않습니다.
  • 마이크(녹음): 사용자가 캐릭터 소리를 직접 녹음할 때만 마이크를 사용합니다. 녹음 파일은 휴대폰 안에만 저장되며, 밖으로 보내지 않습니다.
  • 센서: 기울기·흔들기·화면 접힘 정보는 캐릭터를 움직이는 데만 쓰이고 저장하거나 보내지 않습니다.
  • 설정 내보내기: 사용자가 '내보내기'를 누르면 설정과 사진·소리를 zip 파일로 사용자가 고른 위치에 저장합니다. 이 파일을 어디에 보낼지는 사용자가 정합니다.

2. 프리셋 받기와 구글 로그인 (선택)

설정 화면의 '☁️ 프리셋 더 받기'는 개발자가 올려 둔 프리셋(캐릭터·소리·배경 설정 묶음)을 Google Firebase(Cloud Firestore)에서 내려받습니다. 누구나 받을 수 있는 프리셋은 로그인 없이 받을 수 있습니다.

초대받은 사람만 받을 수 있는 프리셋을 보려면 구글 계정으로 로그인합니다. 이때 Google Firebase Authentication이 구글 계정의 이메일 주소, 이름, 프로필 사진 주소, 계정 식별자를 받아 저장하며, 앱은 이 중 이메일 주소만 초대 대상인지 확인하는 데 씁니다. 이 정보를 광고나 다른 목적에 쓰거나 다른 곳에 제공하지 않습니다.

로그인 정보 삭제를 원하면 아래 이메일로 요청해 주세요. 확인 후 Firebase에 저장된 계정 정보를 지웁니다. 앱의 '로그아웃'은 휴대폰에서만 로그인을 해제합니다. 자세한 처리 방식은 Firebase 개인정보 보호를 참고해 주세요.

3. 자동 배경 지우기(Google ML Kit)

사진에서 캐릭터만 오려 내는 기능은 Google ML Kit를 사용하며, 사진 분석은 휴대폰 안에서 이루어집니다. 다만 ML Kit는 기능 모델을 내려받고 서비스를 개선하기 위해 기기 정보(제조사·모델·OS 버전), 앱 정보(패키지 이름·버전), 설치별 식별자, 성능·오류 정보 같은 진단 정보를 Google에 보낼 수 있습니다. 사진 자체는 보내지 않습니다. 자세한 내용은 ML Kit 데이터 공개와 Google 개인정보처리방침을 참고해 주세요.

4. 제3자 제공

앱은 위 Firebase(로그인·프리셋 저장)와 ML Kit 진단 정보 외에 어떤 정보도 제3자에게 제공하지 않으며, 광고나 분석 도구를 쓰지 않습니다.

5. 정보 삭제

앱 안에 저장된 사진·소리·설정은 앱을 지우거나, 휴대폰 설정 → 애플리케이션 → YuraYura → 저장공간 → 데이터 삭제로 모두 지울 수 있습니다.

6. 아동

앱은 아동을 대상으로 하지 않으며, 로그인하지 않으면 개인정보를 수집하지 않습니다.
