YuraYura 개인정보처리방침

시행일: 2026년 10월 23일

YuraYura(이하 "앱")는 휴대폰 배경화면에 캐릭터가 줄에 매달려 흔들리는 라이브 배경화면 앱입니다. 앱은 회원가입·로그인이 없고, 개인정보를 수집하지 않습니다. 앱이 오류로 꺼졌을 때만 개인정보가 없는 오류 보고서를 보냅니다(4번).

1. 앱이 다루는 정보

  • 사진: 사용자가 직접 고른 사진(배경·캐릭터 이미지)은 휴대폰 안의 앱 저장공간에만 저장되며, 밖으로 보내지 않습니다.
  • 마이크(녹음): 사용자가 캐릭터 소리를 직접 녹음할 때만 마이크를 사용합니다. 녹음 파일은 휴대폰 안에만 저장되며, 밖으로 보내지 않습니다.
  • 센서: 기울기·흔들기·화면 접힘 정보는 캐릭터를 움직이는 데만 쓰이고 저장하거나 보내지 않습니다.
  • 설정 내보내기: 사용자가 '내보내기'를 누르면 설정과 사진·소리를 zip 파일로 사용자가 고른 위치에 저장합니다. 이 파일을 어디에 보낼지는 사용자가 정합니다.

2. 프리셋 받기

설정 화면의 '☁️ 프리셋 더 받기'는 개발자가 올려 둔 프리셋(캐릭터·배경 설정 묶음)을 Google Firebase(Cloud Firestore)에서 내려받습니다. 로그인 없이 동작하며, 내려받을 때 사용자 정보를 보내지 않습니다. 다만 Google 서버와 통신하는 과정에서 IP 주소 같은 접속 정보가 Google에 전달될 수 있습니다. 자세한 내용은 Firebase 개인정보 보호를 참고해 주세요.

3. 자동 배경 지우기(Google ML Kit)

사진에서 캐릭터만 오려 내는 기능은 Google ML Kit를 사용하며, 사진 분석은 휴대폰 안에서 이루어집니다. 다만 ML Kit는 기능 모델을 내려받고 서비스를 개선하기 위해 기기 정보(제조사·모델·OS 버전), 앱 정보(패키지 이름·버전), 설치별 식별자, 성능·오류 정보 같은 진단 정보를 Google에 보낼 수 있습니다. 사진 자체는 보내지 않습니다. 자세한 내용은 ML Kit 데이터 공개와 Google 개인정보처리방침을 참고해 주세요.

4. 오류 보고(Firebase Crashlytics)

앱이 갑자기 꺼지거나 멈추면, 원인을 고치기 위해 Google Firebase Crashlytics로 오류 보고서를 보냅니다. 보고서에는 오류가 난 코드 위치(스택 정보), 기기 정보(제조사·모델·OS 버전), 앱 버전, 메모리·저장공간 상태, 설치별 무작위 식별자가 들어갑니다. 이름·이메일·사진·녹음 같은 개인 정보는 들어가지 않습니다. 오류 보고서는 오류를 고치는 데만 쓰며 광고에 쓰지 않습니다. Firebase는 오류 보고서를 90일 동안 보관합니다. 자세한 내용은 Firebase 개인정보 보호를 참고해 주세요.

5. 제3자 제공

앱은 위 프리셋 내려받기, ML Kit 진단 정보, 오류 보고 외에 어떤 정보도 제3자에게 제공하지 않으며, 광고 도구를 쓰지 않습니다.

6. 정보 삭제

앱 안에 저장된 사진·소리·설정은 앱을 지우거나, 휴대폰 설정 → 애플리케이션 → YuraYura → 저장공간 → 데이터 삭제로 모두 지울 수 있습니다. 이미 보낸 오류 보고서를 지우고 싶으면 아래 문의 메일로 알려 주세요.

7. 아동

앱은 아동을 포함한 누구의 개인정보도 수집하지 않습니다. 오류 보고서에는 개인을 알아볼 수 있는 정보가 들어가지 않습니다.
